# M7 Freunde – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Freundschaftsanfragen per Benutzername, die Sichtbarkeit „👥 Freunde“ für Aktivitäten, ein Leaderboard unter Freunden und ein Hinweis auf offene Anfragen im Profil.

**Architecture:** Das Backend bekommt die Tabelle `friendships` (eine Zeile je Paar, Status `PENDING` oder `ACCEPTED`), ein Paket `friends/` mit Repository, Service und Routen und eine einzige Sichtbarkeitsbedingung im `ActivityRepository`, die Karte und Details teilen. Das Leaderboard wertet bei `scope=FRIENDS` nur die eigene Person und ihre Freunde. Die App bekommt einen Freunde-Screen im Profil, einen dritten Sichtbarkeits-Chip, eine dritte Markerfarbe und eine dritte Chip-Reihe im Leaderboard.

**Tech Stack:** Ktor 3.6, Exposed 1.6, Flyway, PostgreSQL (eingebettet und Neon), Jetpack Compose, Retrofit, kotlinx.serialization.

**Spec:** `docs/superpowers/specs/2026-11-02-freunde-design.md`

## Entscheidungen, die über die Spec hinausgehen

- **Der Körper einer Anfrage heißt `SendFriendRequest`** (`{ "username": "lisa_k" }`), in Backend und App gleich.
- **`UserRepository.findByUsername` sucht nur Benutzernamen,** kleingeschrieben und ohne Leerzeichen am Rand. `findByLogin` fände auch E-Mail-Adressen, und eine Anfrage an eine E-Mail würde verraten, zu welchem Namen sie gehört.
- **Die Sichtbarkeit steht als eine Bedingung `visibleTo(viewerId, friendIds)` im `ActivityRepository`.** Karte (`forMap`) und Details (`findVisible`) nutzen sie. `ActivityService.get` prüft die Sichtbarkeit nicht mehr selbst.
- **`friend` hat im Backend keinen Standardwert** und steht deshalb in jeder Antwort. In der App ist der Standard `false`, damit die vorhandenen Testdaten unverändert passen.
- **Die Antwort des Leaderboards bleibt gleich,** `scope` ist nur ein Parameter. Die App schickt ihn immer mit, Standard `ALL`. Deshalb ändert sich die Erwartung im vorhandenen `SportApiTest` zum Leaderboard.
- **Ablehnen und Zurückziehen** rufen in der App beide `deleteRequest` auf, also `DELETE /friends/requests/{username}`.
- **„Deine Freunde“ erscheint nur, wenn es Freunde gibt,** wie die beiden Listen mit Anfragen. Ohne Freunde und Anfragen steht der Hinweis aus dem Entwurf.
- **Nach dem Senden** nimmt die App den Namen für die Meldung aus der Antwort, also in der gespeicherten Schreibweise: Eingabe `LISA_K`, Meldung „Anfrage an lisa_k gesendet.“
- **Anzeigeregeln sind reine Funktionen,** damit Tests sie prüfen können: `Visibility.label()` (Formular und Details), `groupByOwner()` und `ownerLabel()` (Karte), `openRequestsLabel()` (Profil), `emptyLeaderboardText()` (Leaderboard).
- **Das Profil lädt `GET /friends` als dritten Aufruf** nach `me` und `stats`. Scheitert einer davon, zeigt das Profil wie bisher die Fehlermeldung.
- **`docs/api.md` nennt noch die Basis-URL aus der Zeit vor der Cloud.** Task 9 korrigiert sie, weil die Datei ohnehin geändert wird.
- **In der Probe geprüft:** Der ganze Code dieses Plans lief in einer Kopie des Projekts. Backend 116 Tests, App 107 Unit-Tests, alle grün. **Nicht prüfbar:** Aussehen auf dem Handy und Neon. Das prüft die Testcheckliste nach Task 9.

```kotlin
package de.touchgrass.friends

import de.touchgrass.users.UsersTable
import org.jetbrains.exposed.v1.core.Column
import org.jetbrains.exposed.v1.core.JoinType
import org.jetbrains.exposed.v1.core.Op
import org.jetbrains.exposed.v1.core.Table
import org.jetbrains.exposed.v1.core.and
import org.jetbrains.exposed.v1.core.eq
import org.jetbrains.exposed.v1.core.or
import org.jetbrains.exposed.v1.jdbc.Database
import org.jetbrains.exposed.v1.jdbc.deleteWhere
import org.jetbrains.exposed.v1.jdbc.insert
import org.jetbrains.exposed.v1.jdbc.selectAll
import org.jetbrains.exposed.v1.jdbc.transactions.transaction
import org.jetbrains.exposed.v1.jdbc.update

enum class FriendshipStatus { PENDING, ACCEPTED }

object FriendshipsTable : Table("friendships") {
    val requesterId = long("requester_id")
    val addresseeId = long("addressee_id")
    val status = enumerationByName<FriendshipStatus>("status", 10).default(FriendshipStatus.PENDING)
    override val primaryKey = PrimaryKey(requesterId, addresseeId)
}

data class Friendship(val requesterId: Long, val addresseeId: Long, val status: FriendshipStatus)

/** Eine Verbindung aus Sicht einer Person: Name der anderen Seite, Status und ob die Person selbst angefragt hat. */
data class Connection(val username: String, val status: FriendshipStatus, val outgoing: Boolean)

class FriendshipRepository(private val database: Database) {
    fun between(a: Long, b: Long): Friendship? = transaction(database) {
        FriendshipsTable.selectAll().where { pair(a, b) }.singleOrNull()?.let {
            Friendship(it[FriendshipsTable.requesterId], it[FriendshipsTable.addresseeId], it[FriendshipsTable.status])
        }
    }

    fun request(requesterId: Long, addresseeId: Long) {
        transaction(database) {
            FriendshipsTable.insert {
                it[FriendshipsTable.requesterId] = requesterId
                it[FriendshipsTable.addresseeId] = addresseeId
            }
        }
    }

    fun accept(requesterId: Long, addresseeId: Long) {
        transaction(database) {
            FriendshipsTable.update({ (FriendshipsTable.requesterId eq requesterId) and (FriendshipsTable.addresseeId eq addresseeId) }) {
                it[FriendshipsTable.status] = FriendshipStatus.ACCEPTED
            }
        }
    }

    fun delete(a: Long, b: Long) {
        transaction(database) { FriendshipsTable.deleteWhere { pair(a, b) } }
    }

    fun friendIds(userId: Long): Set<Long> = transaction(database) {
        FriendshipsTable.selectAll()
            .where { involves(userId) and (FriendshipsTable.status eq FriendshipStatus.ACCEPTED) }
            .map { if (it[FriendshipsTable.requesterId] == userId) it[FriendshipsTable.addresseeId] else it[FriendshipsTable.requesterId] }
            .toSet()
    }

    fun connections(userId: Long): List<Connection> = transaction(database) {
        connections(userId, FriendshipsTable.requesterId, FriendshipsTable.addresseeId, outgoing = true) +
            connections(userId, FriendshipsTable.addresseeId, FriendshipsTable.requesterId, outgoing = false)
    }

    private fun connections(userId: Long, own: Column<Long>, other: Column<Long>, outgoing: Boolean): List<Connection> =
        FriendshipsTable.join(UsersTable, JoinType.INNER, other, UsersTable.id)
            .selectAll()
            .where { own eq userId }
            .map { Connection(it[UsersTable.username], it[FriendshipsTable.status], outgoing) }

    private fun involves(userId: Long): Op<Boolean> =
        (FriendshipsTable.requesterId eq userId) or (FriendshipsTable.addresseeId eq userId)

    private fun pair(a: Long, b: Long): Op<Boolean> =
        ((FriendshipsTable.requesterId eq a) and (FriendshipsTable.addresseeId eq b)) or
            ((FriendshipsTable.requesterId eq b) and (FriendshipsTable.addresseeId eq a))
}
```

```kotlin
package de.touchgrass.friends

import de.touchgrass.plugins.ApiException
import de.touchgrass.plugins.validationError
import de.touchgrass.users.UserRecord
import de.touchgrass.users.UserRepository
import io.ktor.http.HttpStatusCode

class FriendService(private val friendships: FriendshipRepository, private val users: UserRepository) {
    fun overview(userId: Long): FriendsDto {
        val connections = friendships.connections(userId)
        fun names(include: (Connection) -> Boolean) = connections.filter(include).map { it.username }.sortedBy { it.lowercase() }
        return FriendsDto(
            friends = names { it.status == FriendshipStatus.ACCEPTED },
            incoming = names { it.status == FriendshipStatus.PENDING && !it.outgoing },
            outgoing = names { it.status == FriendshipStatus.PENDING && it.outgoing },
        )
    }

    fun request(userId: Long, username: String): FriendsDto {
        val name = username.trim()
        if (name.isEmpty()) validationError("username", "Bitte einen Benutzernamen eingeben.")
        val other = users.findByUsername(name)
            ?: throw ApiException(HttpStatusCode.NotFound, "USER_NOT_FOUND", "Diesen Benutzernamen gibt es nicht.", "username")
        if (other.id == userId) validationError("username", "Du kannst dir nicht selbst eine Anfrage schicken.")
        val existing = friendships.between(userId, other.id)
        when {
            existing == null -> friendships.request(userId, other.id)
            existing.status == FriendshipStatus.ACCEPTED ->
                throw ApiException(HttpStatusCode.Conflict, "ALREADY_FRIENDS", "Ihr seid schon befreundet.", "username")
            existing.requesterId == userId ->
                throw ApiException(HttpStatusCode.Conflict, "REQUEST_PENDING", "Du hast schon eine Anfrage geschickt.", "username")
            else -> friendships.accept(existing.requesterId, userId)
        }
        return overview(userId)
    }

    fun accept(userId: Long, username: String): FriendsDto {
        val (_, existing) = connectionWith(userId, username) ?: throw requestNotFound()
        if (existing.status != FriendshipStatus.PENDING || existing.addresseeId != userId) throw requestNotFound()
        friendships.accept(existing.requesterId, userId)
        return overview(userId)
    }

    fun deleteRequest(userId: Long, username: String): FriendsDto {
        val (other, existing) = connectionWith(userId, username) ?: throw requestNotFound()
        if (existing.status != FriendshipStatus.PENDING) throw requestNotFound()
        friendships.delete(userId, other.id)
        return overview(userId)
    }

    fun remove(userId: Long, username: String): FriendsDto {
        val (other, existing) = connectionWith(userId, username) ?: throw notFriends()
        if (existing.status != FriendshipStatus.ACCEPTED) throw notFriends()
        friendships.delete(userId, other.id)
        return overview(userId)
    }

    private fun connectionWith(userId: Long, username: String): Pair<UserRecord, Friendship>? {
        val other = users.findByUsername(username) ?: return null
        return friendships.between(userId, other.id)?.let { other to it }
    }
```

```kotlin
import de.touchgrass.activities.ActivitiesTable
import de.touchgrass.logic.Score
import de.touchgrass.logic.TimeRange
import de.touchgrass.users.UsersTable
import org.jetbrains.exposed.v1.core.JoinType
import org.jetbrains.exposed.v1.core.Op
import org.jetbrains.exposed.v1.core.and
import org.jetbrains.exposed.v1.core.greaterEq
import org.jetbrains.exposed.v1.core.inList
import org.jetbrains.exposed.v1.core.less
import org.jetbrains.exposed.v1.core.sum
import org.jetbrains.exposed.v1.jdbc.Database
import org.jetbrains.exposed.v1.jdbc.select
import org.jetbrains.exposed.v1.jdbc.transactions.transaction

class LeaderboardRepository(private val database: Database) {
    fun scores(range: TimeRange, metric: LeaderboardMetric, onlyUsers: Set<Long>? = null): List<Score> = transaction(database) {
        val total = when (metric) {
            LeaderboardMetric.POINTS -> ActivitiesTable.points.sum()
            LeaderboardMetric.MINUTES -> ActivitiesTable.durationMin.sum()
        }
        var condition: Op<Boolean> = (ActivitiesTable.startedAt greaterEq range.from) and (ActivitiesTable.startedAt less range.until)
        onlyUsers?.let { condition = condition and (ActivitiesTable.userId inList it) }
        ActivitiesTable.join(UsersTable, JoinType.INNER, ActivitiesTable.userId, UsersTable.id)
            .select(UsersTable.id, UsersTable.username, total)
            .where { condition }
            .groupBy(UsersTable.id, UsersTable.username)
            .map { Score(it[UsersTable.id].value, it[UsersTable.username], it[total] ?: 0) }
    }
}
```

```kotlin
package de.touchgrass.ui.friends

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import de.touchgrass.data.ApiException
import de.touchgrass.data.SportApi
import de.touchgrass.data.apiCall
import de.touchgrass.data.dto.FriendsDto
import de.touchgrass.data.dto.SendFriendRequest
import de.touchgrass.ui.UiState
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch

data class FriendsUiState(
    val friends: UiState<FriendsDto> = UiState.Loading,
    val username: String = "",
    val usernameError: String? = null,
    val message: String? = null,
    val error: String? = null,
)

class FriendsViewModel(private val api: SportApi) : ViewModel() {
    private val _state = MutableStateFlow(FriendsUiState())
    val state: StateFlow<FriendsUiState> = _state.asStateFlow()

    fun refresh() {
        viewModelScope.launch {
            val friends = try {
                UiState.Content(apiCall { api.friends() })
            } catch (e: ApiException) {
                UiState.Error(e.message)
            }
            _state.update { it.copy(friends = friends) }
        }
    }

    fun onUsernameChange(value: String) =
        _state.update { it.copy(username = value, usernameError = null, message = null, error = null) }

    fun sendRequest() {
        val name = _state.value.username.trim()
        if (name.isEmpty()) {
            _state.update { it.copy(usernameError = "Bitte einen Benutzernamen eingeben.", message = null) }
            return
        }
        change({ api.sendFriendRequest(SendFriendRequest(name)) }) { friends ->
            val friend = friends.friends.firstOrNull { it.equals(name, ignoreCase = true) }
            val sentTo = friends.outgoing.firstOrNull { it.equals(name, ignoreCase = true) } ?: name
            copy(username = "", message = if (friend != null) "Du und $friend seid jetzt Freunde." else "Anfrage an $sentTo gesendet.")
        }
    }

    fun accept(username: String) = change({ api.acceptFriendRequest(username) }) {
        copy(message = "Du und $username seid jetzt Freunde.")
    }

    fun deleteRequest(username: String) = change({ api.deleteFriendRequest(username) })

    fun remove(username: String) = change({ api.removeFriend(username) })

    private fun change(call: suspend () -> FriendsDto, after: FriendsUiState.(FriendsDto) -> FriendsUiState = { this }) {
        viewModelScope.launch {
            try {
                val friends = apiCall(call)
                _state.update { it.copy(friends = UiState.Content(friends), message = null, error = null).after(friends) }
            } catch (e: ApiException) {
                _state.update {
                    if (e.field == "username") it.copy(usernameError = e.message, message = null)
                    else it.copy(error = e.message, message = null)
                }
            }
        }
    }
}
```

```kotlin
@Composable
fun FriendsScreen(viewModel: FriendsViewModel, onBack: () -> Unit) {
    val state by viewModel.state.collectAsStateWithLifecycle()
    var confirmRemove by remember { mutableStateOf<String?>(null) }
    LaunchedEffect(Unit) { viewModel.refresh() }

    Column(
        modifier = Modifier.fillMaxSize().verticalScroll(rememberScrollState()).padding(16.dp),
        verticalArrangement = Arrangement.spacedBy(12.dp),
    ) {
        TextButton(onClick = onBack) { Text("← Zurück") }
        Text("👥 Freunde", style = MaterialTheme.typography.headlineMedium)
        FormField(state.username, viewModel::onUsernameChange, "Benutzername", state.usernameError)
        Button(onClick = viewModel::sendRequest, modifier = Modifier.fillMaxWidth()) { Text("Anfrage senden") }
        state.message?.let { Text(it, color = MaterialTheme.colorScheme.primary) }
        state.error?.let { Text(it, color = MaterialTheme.colorScheme.error) }
        when (val s = state.friends) {
            UiState.Loading -> LoadingIndicator()
            is UiState.Error -> {
                Text(s.message, color = MaterialTheme.colorScheme.error)
                TextButton(onClick = viewModel::refresh) { Text("Erneut versuchen") }
            }
            is UiState.Content -> FriendLists(
                friends = s.data,
                onAccept = viewModel::accept,
                onDeleteRequest = viewModel::deleteRequest,
                onRemove = { confirmRemove = it },
            )
        }
    }

    confirmRemove?.let { name ->
        AlertDialog(
            onDismissRequest = { confirmRemove = null },
            title = { Text("Freundschaft mit $name beenden?") },
            text = { Text("Ihr seht dann eure „👥 Freunde“-Aktivitäten nicht mehr.") },
            confirmButton = { TextButton(onClick = { confirmRemove = null; viewModel.remove(name) }) { Text("Beenden") } },
            dismissButton = { TextButton(onClick = { confirmRemove = null }) { Text("Abbrechen") } },
        )
    }
}

@Composable
private fun FriendLists(
    friends: FriendsDto,
    onAccept: (String) -> Unit,
    onDeleteRequest: (String) -> Unit,
    onRemove: (String) -> Unit,
) {
    if (friends.friends.isEmpty() && friends.incoming.isEmpty() && friends.outgoing.isEmpty()) {
        Text("Noch keine Freunde. Schick jemandem eine Anfrage über seinen Benutzernamen.")
        return
    }
    if (friends.incoming.isNotEmpty()) {
        Text("Anfragen an dich", style = MaterialTheme.typography.titleMedium)
        friends.incoming.forEach { name ->
            ListItem(
                headlineContent = { Text(name) },
                trailingContent = {
                    Row {
                        TextButton(onClick = { onAccept(name) }) { Text("Annehmen") }
                        TextButton(onClick = { onDeleteRequest(name) }) { Text("Ablehnen") }
                    }
                },
            )
        }
    }
    if (friends.friends.isNotEmpty()) {
        Text("Deine Freunde", style = MaterialTheme.typography.titleMedium)
        friends.friends.forEach { name ->
            ListItem(
                headlineContent = { Text(name) },
                trailingContent = { TextButton(onClick = { onRemove(name) }) { Text("Entfernen") } },
            )
        }
    }
    if (friends.outgoing.isNotEmpty()) {
        Text("Gesendete Anfragen", style = MaterialTheme.typography.titleMedium)
        friends.outgoing.forEach { name ->
            ListItem(
                headlineContent = { Text(name) },
                trailingContent = { TextButton(onClick = { onDeleteRequest(name) }) { Text("Zurückziehen") } },
            )
        }
    }
}
```
